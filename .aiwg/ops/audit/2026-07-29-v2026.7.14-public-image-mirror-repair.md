# v2026.7.14 Public Image Mirror Repair Audit

date: 2026-07-29
release: v2026.7.14
systems:
  - agentic-sandbox
  - gitea-actions
  - gitea-container-registry
  - ghcr

## Scope

Repair the failed public container-image mirror from release CI run `#2846`
without moving the signed release tag or replacing any published release
asset.

## Impact

The Gitea and GitHub release records, unsigned Apple Silicon developer
package, checksums, manifests, and evidence were published and verified.
Public GHCR publication stopped after the management and Rust agent-client
images because the mirror could not resolve the internal
`agent:v2026.7.14` source tag. Five image-chain packages were absent from
GHCR.

## Root Cause

The multi-architecture publisher introduced explicit
`agent:base-v<version>` and `agent:dev-v<version>` tags but did not preserve
the historical generic `agent:v<version>` compatibility alias. The public
mirror and signing jobs still consumed that generic alias. Before the
multi-architecture migration, both agent stages wrote the generic tag and the
developer stage wrote it last, so the public contract resolved to the
developer image.

## Mitigation

- Created `agent:v2026.7.14` from the existing immutable
  `agent:dev-v2026.7.14` OCI index.
- Verified both internal references resolve to manifest digest
  `sha256:86c7c815e3a93d7e666b633d56ea97aa3afa6409720706668704ecbdb122aaa2`.
- Retried the failed release publication path.
- Left signed tag `v2026.7.14` and all release assets unchanged.

## Preventive Fix

`scripts/build-multiarch-agent-images.sh` now emits generic agent revision and
release aliases from the developer-stage build. Its contract test proves each
alias is emitted exactly once. The release runbook records the mapping between
the explicit image-chain tag and the public package source. The GHCR matrix
test is restored to `make test-scripts` and aligned with Vault-backed token
retrieval so it cannot silently drift outside routine CI again.

## Verification

- Shell syntax and ShellCheck pass.
- `tests/container/test-multiarch-build-contract.sh` passes.
- `git diff --check` passes.
- Anonymous pulls of all seven `v2026.7.14` GHCR images are required before
  this repair is closed.
