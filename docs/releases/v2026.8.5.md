# Agentic Sandbox v2026.8.5

**Released:** 2026-08-21  
**Tag:** `v2026.8.5`  
**Previous tag:** `v2026.8.4`  
**Compare:** [`v2026.8.4...v2026.8.5`](https://github.com/jmagly/agentic-sandbox/compare/v2026.8.4...v2026.8.5)

## What changed

This patch bounds libvirt checkpoint save and managed-save operations with
TERM/KILL deadlines, removes partial checkpoint artifacts after a timeout, and
forces bounded cleanup when the disposable self-test domain remains active.
The post-E2E checkpoint/restore probe also has a hard outer timeout and retains
its diagnostic log on failure.

An apply-gated recovery workflow is available for older or already-wedged
runs. It matches only the fixed `chkpt-selftest-base`/`chkpt-selftest` domains,
the self-test checkpoint path, and `/var/tmp/chkpt-selftest`. After successful
cleanup it can schedule a restart of the deployed build01 Actions runner. The
workflow does not touch user VMs or general checkpoint storage.

## Upgrade

Upgrade `agentic-mgmt`, `agent-client`, and `agentic-cli` together. Linux
package users can use the published installer:

```bash
curl -fsSLO https://github.com/jmagly/agentic-sandbox/releases/download/v2026.8.5/agentic-sandbox-install.sh
bash agentic-sandbox-install.sh --version v2026.8.5
```

Verify downloaded artifacts and public images using the
[release verification guide](verification.md).

## Qualification boundary

This patch does not change the v2026.8.4 qualification boundary. Celld remains
experimental and off by default. Live object-store, multi-node fleet,
provider-fault, network-isolation, soak, and human UAT evidence remains open;
local filesystem storage and mounted volumes remain first-class options.

## Rollback

Rollback management, agent, and CLI binaries together to v2026.8.4. The
checkpoint timeout and recovery changes do not alter persisted VM or storage
formats.
